# 🧩 Maze Escape Light (Pygame)

Un jeu de **Labyrinthe/Puzzle** stratégique et épuré développé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🗺️ **Grille de Labyrinthe :** Guidez votre personnage à travers les couloirs pour atteindre la sortie dorée.
- ⌨️ **Contrôles fluides :** Déplacement case par case avec les flèches directionnelles ou les touches `ZQSD` / `WASD`.
- 📊 **Compteur de pas :** Suivi du nombre de déplacements pour optimiser votre parcours.
- 🔄 **Rejouabilité instantanée :** Touche `ESPACE` pour relancer une partie après la victoire.

---

pip install pygame
